# Mizan Beauty Shop - ওয়েবসাইট

এটি একটি সহজ PHP-তে তৈরি বিউটি শপ ওয়েবসাইট যেখানে WhatsApp দিয়ে অর্ডার নেওয়া যায়।

## ফাইলগুলি
- `index.php` — মূল ওয়েবসাইট পেজ
- `style.css` — ডিজাইন ও স্টাইলিং
- `README.md` — এই নির্দেশনা

---

## ১. স্থানীয়ভাবে চালানোর নিয়ম (আপনার কম্পিউটারে)

### প্রথম ধাপ: PHP ইনস্টল করুন
- **Windows/Mac/Linux** — PHP ডাউনলোড করুন: https://www.php.net/downloads
- অথবা XAMPP/WAMP ডাউনলোড করুন (সহজ)

### দ্বিতীয় ধাপ: ফোল্ডার তৈরি করুন
1. কোথাও একটি ফোল্ডার তৈরি করুন, যেমন: `C:\mizan-beauty` বা `~/mizan-beauty`
2. এই রিপোজিটরির সব ফাইল সেখানে কপি করুন

### তৃতীয় ধাপ: টার্মিনাল খুলুন
1. **Windows**: `Command Prompt` বা `PowerShell` খুলুন
2. **Mac/Linux**: `Terminal` খুলুন
3. ফোল্ডারে যান:
```bash
cd C:\mizan-beauty
```

### চতুর্থ ধাপ: PHP সার্ভার চালু করুন
```bash
php -S localhost:8000
```

### পঞ্চম ধাপ: ব্রাউজারে খুলুন
ব্রাউজারে এই লিংক খুলুন:
```
http://localhost:8000
```

আপনার ওয়েবসাইট দেখা যাবে! 🎉

## ৩. Online Live করার নিয়ম

তিনটি সহজ উপায়:

### **অপশন A: GitHub Pages (সম্পূর্ণ বিনামূল্যে, কিন্তু সীমাবদ্ধ)**
- GitHub Pages সরাসরি PHP সাপোর্ট করে না
- ব্যবহার করুন: Vercel বা Netlify (নিচে দেখুন)

### **অপশন B: Vercel (সেরা, বিনামূল্যে)**
1. vercel.com-এ যান এবং লগইন করুন
2. এই GitHub রিপোজিটরি import করুন
3. Vercel আপনার সাইট স্বয়ংক্রিয়ভাবে deploy করবে
4. পাবেন একটি লাইভ লিংক: `https://mizan-beauty-shop.vercel.app`

### **অপশন C: Netlify (বিনামূল্যে, সহজ)**
1. netlify.com-এ যান এবং GitHub দিয়ে লগইন করুন
2. এই রিপোজিটরি নির্বাচন করুন
3. Deploy করুন — সম্পূর্ণ!

### **অপশন D: পেইড হোস্টিং (সবচেয়ে নির্ভরযোগ্য)**
- Hostinger, Bluehost, SiteGround ইত্যাদি থেকে PHP হোস্টিং কিনুন
- FTP দিয়ে ফাইল আপলোড করুন
- আপনার ডোমেইন যুক্ত করুন

## ৫. তাদের কম্পিউটারে চালানোর নিয়ম

আপনি তাদের এই নির্দেশনা দিন:

### তাদের জন্য নির্দেশনা:

1. **GitHub থেকে ডাউনলোড করুন**
   - এই লিংক খুলুন: https://github.com/shazzad412/mizan-beauty-shop
   - সবুজ "Code" বাটন ক্লিক করুন
   - "Download ZIP" নির্বাচন করুন
   - ZIP ফাইলটি ডাউনলোড হবে

2. **ZIP extract করুন**
   - ডাউনলোড করা ZIP ফাইল right-click করুন
   - "Extract All" বা "এখানে extract করুন" নির্বাচন করুন

3. **PHP ইনস্টল করুন** (যদি না থাকে)
   - https://www.php.net/downloads থেকে ডাউনলোড করুন
   - অথবা XAMPP/WAMP দিয়ে ইনস্টল করুন

4. **টার্মিনাল খুলুন এবং এটি টাইপ করুন:**
   ```bash
   cd [যেখানে ZIP extract করেছেন]
   php -S localhost:8000
   ```

5. **ব্রাউজারে খুলুন:**
   ```
   http://localhost:8000
   ```

ফেরাই! ওয়েবসাইট তাদের কম্পিউটারে চলবে। 🚀
